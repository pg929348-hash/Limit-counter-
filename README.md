
🔢 Limit Counter

📌 About
This project counts how many numbers in a list are smaller than a given limit. Simple and super useful for filtering data.

✨ How It Works
- 📝 You give it a list of numbers
- 🎯 You also give it a limit value
- 👀 It checks each number one by one
- ➕ If the number is smaller than the limit, it adds 1 to the count
- 🔢 At the end, it tells you the total count

✅ Example Flow
- 📥 Input list is like 23, 34, 23, 1123, 10, 23
- 🎯 Limit is set to 20
- 🔍 It will check all numbers
- ✨ Only numbers smaller than 20 will be counted
- 📊 Final result is the total count

💡 Use Cases
- 📊 Data filtering
- 🧮 Counting low scores / low prices
- 🎓 Perfect for beginners to learn loops and condition
- 💼 Useful in interviews and basic DSA practice

🚀 Features
- ⚡ Fast and simple
- 🔁 Works with any size of list
- 🎯 Works with any limit value
